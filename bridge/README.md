# Obsidian 文献归档桥

这是安装在 Zotero 内的配套插件，统一归档双语全文、指南、图解、DSH/Awesome GPT 讨论和 PDF 标注。无需额外的 Obsidian 插件。

公开构建版本 0.3.7。首次安装后，打开 **工具 → Obsidian 文献笔记**，选择你的 Obsidian 库目录；没有预设作者的磁盘路径。默认相对笔记文件夹为 `文献阅读`。

笔记中的个人整理区、自定义属性和管理区外文本保留。讨论与精读先保存到本地队列，再尝试更新库；Obsidian 关闭时仍能写入可访问的库目录。

构建与测试可从仓库根目录运行 `npm run build` 和 `npm run test:bridge`。完整接入见根目录 `docs/INSTALL.md`。
