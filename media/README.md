# 宣传素材

`screenshots/` 中的主界面素材为 1920×1080 PNG，来自正式插件前端运行本项目原创演示数据的画面。`cover-portrait.png` 为 1080×1920 封面。

| 文件 | 用途 |
|---|---|
| `cover-landscape.png` | 横屏视频封面 |
| `cover-portrait.png` | 竖屏视频封面 |
| `01-overview.png` | 双语正文与分类重点 |
| `02-figure.png` | 图表与解读左右分栏 |
| `03-chat.png` | 窗口内对话与引用 |
| `04-guide.png` | 阅读指南 |
| `05-note.png` | 归档模块生成的 Markdown 预览 |

均可按项目 MIT 许可使用与剪辑。演示不包含个人文献或出版社图片，示例数值和预置回答不代表科研结果或模型性能。分镜和口播稿见本目录对应文件。
